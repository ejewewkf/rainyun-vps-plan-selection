## 8 元那档到底够不够用

够用，但边界很窄：1GB 空间、100MB 数据库、每月 10GB 流量，撑一个纯文字的博客没问题，撑一个图片全放自己服务器上的站就不行了。

把流量换算成你熟悉的单位更直观。10GB 一个月，按 30 天算是日均约 330MB；50GB 档日均约 1.6GB；100GB 档日均约 3.3GB。

一个优化过的网页，含图片通常在 500KB 到 1MB 之间。按 500KB 算，10GB 流量大约对应 2 万次页面访问。日均几百次浏览的个人博客，这个量绰绰有余；一旦你把文章配图、主题图片、访客头像全放在站内，单页体积很容易涨到 2MB 以上，可访问量会掉到五千次左右。所以对入门型的正确用法是：图片走图床或对象存储，站点只放文字和样式。

数据库 100MB 这个限制更值得留意。如果你打算装 WordPress，程序本身加上插件、文章修订版本、评论表，数据库涨得比想象中快。写几百篇纯文字文章、不装重型插件，100MB 能撑一段时间；但只要开了电商插件、表单插件，或者文章里塞大量自定义字段，这个额度会很快不够用。

按这个逻辑分三档：

- **纯文字博客、访问量不大、图片外链**：入门型够，先用一个月看真实流量再决定要不要升。
- **图文混排的个人站、小程序或 App 后端、日均几百 IP**：标准型。5GB 空间能放几千张压缩过的配图，500MB 数据库对 WordPress 也宽松不少。
- **图库型站点、文章配图多且不想折腾图床**：进阶型。10GB 空间和 100GB 流量是给“图片就想放站内”的人准备的。

## 虚拟主机、云服务器、NAT 机型：到底差在哪

虚拟主机是共享环境、免运维、开箱即用；云服务器给你一台完整的机器，能装任意系统和软件；NAT 机型是云服务器里最便宜的一类，但它不适合对外提供网站服务。

虚拟主机这条线，雨云预装了宝塔或 1Panel 面板，WordPress、Typecho、Discuz 等八种应用可以一键部署。你不用管系统更新、不用配 PHP 和数据库、不用碰防火墙，域名解析过去就能开始写文章。代价是你也装不了自定义的编译环境、跑不了需要特定扩展的程序。

云服务器（ECS）是 KVM 虚拟化，Linux 和 Windows 都能装，处理器用 Intel Xeon Platinum 和 AMD EPYC 7702，按天计费，配置和带宽可以随时升降。你要跑 Docker、要装特殊版本的 PHP、要做反向代理，只有这条路。

NAT 机型的问题在这里：它共用公网 IP，外部端口一般随机生成。雨云论坛的 VPS 教程在讲端口映射时特别标注，外部端口“一般随机生成即可”，紧接着就是那句加粗三遍的“请不要用来建站”“国内禁TCP建站哦”。也就是说，你买一台便宜的 NAT 云服务器，想绑域名对外提供 80/443 服务，方向就是错的。NAT 机型适合挂机器人、跑脚本、开游戏服这类走非标准端口、不需要域名访问的场景。

想建站又想用云服务器，得选带独立公网 IP 的机型；至于独立 IP 要不要另外加钱、加多少，官网价格页和购买页上写得更清楚，第三方说法彼此对不上，我不在这里给你一个可能过期的数字。
